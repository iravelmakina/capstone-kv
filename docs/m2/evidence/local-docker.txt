Local cluster in Docker: coordinator + shard-1 + shard-2 from one image (docker-compose.yml).
2026-11-24, Docker Desktop 28.4, image capstone-kv:local (8.4 MB).

===== [L1] first start: permission bug found and fixed =====
$ make local-up
coordinator-1  | open table registry: mkdir /data/tables: permission denied
shard-1-1      | open store: mkdir /data/shard: permission denied
# Cause: the container runs as non-root (distroless "nonroot", UID 65532) but the /data
# volume was created owned by root. Fix in the Dockerfile: copy an empty /data owned by
# nonroot into the image; a new named volume inherits that ownership.

===== [L2] after the fix: cluster ready =====
$ curl -s localhost:8080/health
{"ready":true,"role":"coordinator","shards":2,"status":"ok"}
$ curl -s localhost:8080/internal/v1/shards
[{"id":"shard-1","address":"http://shard-1:8080","available":true,"silentFor":"0s"},{"id":"shard-2","address":"http://shard-2:8080","available":true,"silentFor":"0s"}]
